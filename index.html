คำถามที่พบบ่อย

ถ้ายังสงสัย ทักไลน์ถามได้เลย

โปรแกรมทำให้บัญชี Shopee ถูกแบนไหม?

มีระบบ Anti-ban ลดความเสี่ยง (ดีเลย์สุ่ม + คูลดาวน์ + จำลองการพิมพ์) แต่ไม่รับประกัน 100% — หากใช้งานเกิน 45 คลิป/บัญชี/วัน เสี่ยงสูง แนะนำใช้พอดี ตามกฎ Shopee

ต้องใช้ Windows อะไร?

Windows 10 หรือ 11 (64-bit) · ต้องเชื่อมมือถือ Android ผ่านสาย USB หรือ Wi-Fi ADB · ต้องมีเน็ตสำหรับ AI

1 Key ใช้ได้กี่เครื่อง?

1 License Key ผูกกับ 1 คอมพิวเตอร์เท่านั้น (ระบุด้วย Machine ID ของ Windows) ย้ายเครื่องต้องขอ key ใหม่ — ไม่สามารถใช้ key เดียวบนหลายเครื่องได้

รองรับมือถือกี่เครื่องพร้อมกัน?

สูงสุด 6 มือถือพร้อมกัน — แต่ละมือถือ login บัญชี Shopee คนละบัญชี (1 บัญชี Shopee ต่อ 1 มือถือ ป้องกัน Shopee จับว่าผิดปกติ)

AI ค่าใช้จ่ายเท่าไหร่?

ใช้ API key ของ OpenAI หรือ Gemini ของลูกค้าเอง ค่าใช้จ่ายประมาณ ฿0.10–0.30 ต่อ caption (น้อยมาก) Gemini มี free tier ให้ใช้ฟรี

มีคู่มือการใช้งานไหม?

มีคู่มือฉบับเต็มสำหรับลูกค้าเมื่อซื้อ key — สอนตั้งแต่ติดตั้ง เชื่อมมือถือ ตั้ง AI provider จนถึงอัปโหลดจริง

พร้อมเริ่มอัปโหลดอัตโนมัติแล้ว?

ทดลองฟรี 3 วัน — ไม่ต้องผูกบัตรเครดิต
